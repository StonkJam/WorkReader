Reader settings

WorkReader is an independent reader with Outlook-style branding and a fictional mail view. The reader runs from your USB. GitHub collects the listings separately. Enter your public repository as username/repository, or paste the HTTPS address of data/deals.json.

Use a public data file. Never paste a password or GitHub token. Settings live in this browser; Export includes them so you can move your setup to another computer.

Mail view and inactivity

Space switches between reading and a sample mailbox. Mail view removes real posts, source names and images from the visible panes, and closes open dialogs. Your reading position is restored when you return; image previews stay collapsed. The sample mailbox is fictional and cannot send email.

Clicks, typing, scrolling and touch reset the timer. Moving the pointer alone does not. Returning to the tab also checks elapsed time.

Source status

Refresh downloads the latest snapshot. It does not start a new GitHub scan. A source timestamp records its own last successful scan, which may be older than the data file.

Capture from an open page

For a source that cannot be scanned automatically, use this bookmark on its own page. It reads the visible deal cards and downloads a JSON file you can import here.

Capture deals
  1. Drag Capture deals onto your bookmarks bar. If dragging is blocked, use Copy bookmark code and save it as a bookmark’s address.
  2. Open the Jetstar, JB, OzBargain or Reddit page normally. For JB, apply the Clearance filter and wait for the products to load.
  3. Click the bookmark. Import the downloaded JSON file using the reader’s Import button.
Captures contain only cards the extractor recognises. JB items must explicitly say “Clearance”. Multiple prices are left unpriced unless a sale-price element is identifiable. Some browsers or websites may block bookmarklets.

Watch searches

Save a keyword search, such as “iPad Pro”, “Bali” or “SSD”. Matching items appear in its folder whenever you load fresh data. Searches are case-insensitive; words are matched together.

This is a saved filter. It does not send notifications or scan while the reader is closed.

Raindrop.io

Browse your collections and save an open item. Create a personal app in Raindrop integration settings, then use its Test token here.

The token and private bookmarks stay in memory for this session. They are excluded from GitHub, browser storage and exports. Reconnect after reopening the file.
